# Roadmap

The GpSharp SDK roadmap outlines the planned development phases for the SDK.

## Phase 1: Foundation & HTTP (Current)
- [x] Project setup and build configuration
- [x] Core identity types (`GoProId`, `NetworkType`)
- [x] HTTP communication layer implementation
- [x] Network Discovery (UDP/mDNS)
- [x] Command, Settings, and Status containers
- [x] Integration tests for connection flow
- [ ] Full documentation in `docs/`

## Phase 2: BLE Implementation
- [ ] Bluetooth Low Energy (BLE) discovery
- [ ] BLE connection management
- [ ] BLE command/setting/status operations
- [ ] Feature parity with HTTP where possible

## Phase 3: Advanced Features & Polish
- [ ] AccessPointFeature and LivestreamFeature implementation
- [ ] Media file access and streaming support
- [ ] Robust keep-alive signal management
- [ ] Sample application development
- [ ] Full ecosystem of diagnostics and logging tools
